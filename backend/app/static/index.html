Verification evidence

This demo reports challenge evidence only. It has no validated face deepfake, speaker verification, or audio anti-spoof model, so the final decision remains Review.

Privacy for this demo: video stays in the browser and is not yet analyzed by a classifier. Only scanned QR observations and capture duration are sent to the API. Phone biometrics stay on-device; the API receives and verifies a signed public-key assertion. Session data is in memory and clears when the API restarts.
